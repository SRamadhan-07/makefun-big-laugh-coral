# One Line, Big Laugh

![Competition](https://make.fun/badge/u-coral-404-one-line-big-laugh-328fb857.svg)
![Rank](https://make.fun/badge/u-coral-404-one-line-big-laugh-328fb857/SRamadhan-07/makefun-big-laugh-coral/rank.svg)
![Reward](https://make.fun/badge/u-coral-404-one-line-big-laugh-328fb857/SRamadhan-07/makefun-big-laugh-coral/reward.svg)

A Python program (standard library only) that writes one big-laugh line to
`/output/entry.txt`:

> Retirement plan: I'm saving every 'per my last email' until I can afford a personality.

The line is a retirement plan funded entirely by passive-aggressive email
sign-offs — saving each one until it finally buys back a personality.

Competition: [One Line, Big Laugh on make.fun](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857)

## Run

```sh
python3 main.py
cat /output/entry.txt
```
